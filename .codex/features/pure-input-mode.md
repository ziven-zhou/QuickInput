# 纯净输入模式与输入框字体大小需求说明

## 文档状态

- 状态：已实现。
- 范围：主输入窗口 `main` 和设置窗口 `settings`。
- 目标版本：当前版本。
- 更新时间：2026-11-12。

## 已确认结论

1. 纯净模式正常状态下只显示输入框，错误发生时允许短暂显示错误提示。
2. 纯净模式使用设置中的默认内容模式，不强制切换为纯文本。
3. 纯净模式不允许拖动和手动调整窗口大小，窗口位置和尺寸由设置控制。
4. 功能名称使用“纯净输入模式”。
5. 新增“输入框字体大小”设置，默认 `14px`，可在 `12px` 到 `32px` 之间调整。

## 需求背景

当前主输入窗口同时展示模式选择、字符数、清空、保存、取消、确认、状态提示和底部快捷键栏。用户希望增加一个可选的纯净输入模式，开启后主页面只保留输入框，减少视觉干扰，专注于快速输入和粘贴。

## 用户故事

作为经常使用 QuickInput 的用户，我希望在设置中开启“纯净输入模式”，这样唤起输入框时只看到输入区域，不需要看到工具栏、按钮、状态栏和其它辅助信息。

作为需要长时间输入的用户，我希望可以调整输入框字体大小，使输入内容在不同屏幕和视觉条件下都保持清晰舒适。

## 设置项

在设置窗口的“窗口”区域新增以下控件：

```text
纯净输入模式    [开关]
输入框字体大小  [12px ─────●──── 32px]  14px
```

建议配置字段名：

```text
pure_mode: bool
input_font_size: u32
```

默认值：

```text
pure_mode = false
input_font_size = 14
```

设置保存后立即生效，并持久化到 `settings.json`。旧版本设置文件没有对应字段时，`pure_mode` 按关闭处理，`input_font_size` 按 `14` 处理。

## 页面呈现

### 普通模式

保持当前结构：

```text
┌──────────────── 主窗口 ────────────────┐
│ 模式  提示  字符数  清空 保存 取消 确认 │
├─────────────────────────────────────────┤
│                                         │
│               输入框                    │
│                                         │
├─────────────────────────────────────────┤
│ 快捷键提示                 内容库 设置   │
└─────────────────────────────────────────┘
```

### 纯净输入模式

开启后主窗口只显示输入区域：

```text
┌──────────────── 主窗口 ────────────────┐
│                                         │
│               输入框                    │
│                                         │
└─────────────────────────────────────────┘
```

已确认隐藏以下元素：

- 顶部模式选择器。
- 模式提示。
- 字符数。
- 清空按钮。
- 取消按钮。
- 确认按钮。
- 底部快捷键提示。
- 内容库和设置文字入口。
- 右下角调整大小手柄。
- Markdown 预览区域。

窗口背景、透明度和圆角等容器样式可以保留，但输入框不应再出现工具栏或状态栏占位。

## 键盘操作

纯净输入模式不增加可见按钮，核心操作继续使用快捷键：

| 操作 | 默认快捷键 | 是否保留 |
| --- | --- | --- |
| 唤起输入框 | `Alt+Space` | 保留，系统全局 |
| 确认并粘贴 | `Alt+Enter` | 保留，窗口内 |
| 取消 | `Escape` | 保留，窗口内 |
| 清空输入 | `Alt+Backspace` | 保留，窗口内 |
| 打开内容库 | `Alt+R` | 保留，系统全局 |
| 打开设置 | `Alt+S` | 保留，系统全局 |

`Enter` 仍用于输入换行，不改成确认，避免破坏多行输入习惯。

## 内容模式

纯净模式只改变可见 UI，不建议复制一套新的粘贴逻辑。输入内容仍通过现有 `confirm_input` 命令处理。

已确认行为：

- 主窗口唤起时仍读取 `default_mode`。
- 如果默认模式是 `plain`，输入框使用普通文本样式。
- 如果默认模式是 `markdown`，仍可按 Markdown 格式粘贴，但纯净模式不显示实时预览。
- 旧 `code` 模式在加载时按 `plain` 处理。

## 设置实现

“纯净输入模式”和“输入框字体大小”已放在设置窗口“窗口”分区，与窗口位置、尺寸和透明度属于同一类。

保存时需要同步修改：

1. `Settings` 增加 `pure_mode` 字段，并使用默认值 `false`。
2. `Settings` 增加 `input_font_size` 字段，并使用默认值 `14`。
3. `src/settings.js` 的本地默认设置对象增加 `pure_mode` 和 `input_font_size`。
4. 设置加载时恢复开关和字体大小。
5. 设置变化后自动提交两个字段。
6. 保存成功后通过现有 `page-shortcuts-updated` 事件通知主窗口刷新。

不建议新增独立 Tauri 命令，继续复用 `get_settings` 和 `save_settings`。

## 主窗口实现

实现没有复制 `index.html`，而是通过状态类切换界面：

```text
input-window pure-mode
```

实现流程：

1. 主窗口初始化时读取 `pure_mode`。
2. 根据配置给 `#app` 添加或移除 `pure-mode` 类。
3. 收到 `page-shortcuts-updated` 后重新读取设置并刷新类名。
4. CSS 在 `pure-mode` 下隐藏工具栏、状态提示、底部栏和调整大小手柄。
5. 输入区域占满主窗口可用空间。
6. 通过 CSS 变量应用输入框字体大小。

这样可以保持现有 HTML 结构和事件绑定不变，降低对确认、取消和 Markdown 实时预览逻辑的侵入。

## 窗口移动和尺寸

当前拖动和调整大小依赖可见的工具栏与右下角手柄。纯净模式隐藏它们后，采用以下已确认规则：

- 纯净模式不允许拖动和手动调整大小。
- 窗口位置继续由“窗口弹出位置”和“记住上次窗口位置”控制。
- 窗口尺寸继续由设置中的默认宽高控制。
- 需要调整大小时，关闭纯净模式或先在设置中修改尺寸。

## 错误和状态提示

纯净模式下如果完全隐藏 `status-msg`，用户将看不到以下信息：

- 内容为空。
- 辅助功能权限不足。
- 剪贴板写入失败。
- 粘贴失败。
- 取消失败。

已确认行为：

- 正常输入状态下不显示状态提示。
- 内容为空、权限不足、剪贴板写入失败、粘贴失败或取消失败时，短暂显示一条错误信息。
- 错误信息可以覆盖在窗口底部或输入框内部，约 4 秒后自动消失。
- 提示消失后仍保持纯净布局。

## 输入框字体大小

### 设置控件

字体大小设置放在设置窗口“窗口”区域，建议使用滑杆，并实时显示当前值和一段示例文本。

```text
输入框字体大小
[12px ─────────●──────── 32px]  14px

QuickInput 字体预览
```

建议参数：

| 参数 | 值 |
| --- | --- |
| 字段名 | `input_font_size` |
| 类型 | `u32` |
| 默认值 | `14` |
| 最小值 | `12` |
| 最大值 | `32` |
| 步长 | `1` |
| 单位 | `px` |

设置页拖动滑杆时，示例文本立即更新；停止拖动约 220ms 后自动保存，主输入窗口随后应用新字号。

### 生效范围

- 普通模式下输入框字体大小生效。
- 纯净模式下输入框字体大小同样生效。
- `plain` 模式使用当前系统 UI 字体，字号由设置决定。
- Markdown 模式的编辑输入区使用设置字号，Markdown 预览区域保持现有独立字号。
- 工具栏、按钮、字符数、快捷键提示、内容库页面和设置页面不跟随输入框字号变化。

实现使用 CSS 变量：

```css
:root {
  --input-font-size: 14px;
}

.input-area {
  font-size: var(--input-font-size);
}
```

### 加载和刷新

1. 主窗口初始化时读取 `input_font_size`。
2. 将字号写入 `--input-font-size`，例如 `14px`。
3. 收到 `page-shortcuts-updated` 后重新读取设置并更新变量。
4. 字号异常、缺失或超出范围时，使用 `14px` 作为回退值。
5. 字号变化不修改输入内容、内容模式或剪贴板格式。

### 边界情况

- 字号为 `32px` 且窗口较小时，输入区应出现滚动，不得导致工具栏或底部栏溢出。
- 纯净模式切换和字体大小调整可以在同一个设置保存操作中完成。
- 字体大小不影响 Markdown 预览的标题、正文和代码块排版。

## 不受影响的功能

- 全局快捷键注册和冲突校验。
- 唤起前前台应用 PID 记录。
- 剪贴板快照、恢复和粘贴模拟。
- 内容库页面。
- 托盘菜单。
- 设置持久化。
- `keep_open_on_confirm` 行为。

内容库是独立的手动内容入口，不依赖纯净模式或主输入页面的保存按钮。

## 边界情况

- 设置窗口保持打开时切换纯净模式，主窗口应在保存后同步刷新，不需要重启应用。
- 旧 `settings.json` 没有 `pure_mode` 字段时，主窗口应保持普通模式。
- 旧 `settings.json` 没有 `input_font_size` 字段时，输入框使用 `14px`。
- `input_font_size` 非法或超出 `12-32` 时，输入框回退到 `14px`。
- 纯净模式下按 `Alt+R` 或 `Alt+S` 仍应打开对应窗口。
- 纯净模式下无可见取消按钮，`Escape` 必须继续可靠工作。
- 如果 `keep_open_on_confirm = true`，确认后窗口保持打开，但输入区域会被清空。

## 验收标准

- 设置窗口中存在“纯净输入模式”开关。
- 开关默认关闭，保存后重启应用仍保持状态。
- 设置窗口中存在“输入框字体大小”滑杆，默认 `14px`，范围为 `12px` 到 `32px`。
- 拖动字体大小滑杆时，设置页示例文本立即变化。
- 保存字体大小后，普通模式和纯净模式的输入框都立即更新，不需要重启应用。
- `plain` 和 Markdown 编辑区都使用设置的字号。
- Markdown 预览区域保持独立字号。
- 字体大小设置保存后重启应用仍保持状态。
- 旧设置文件缺少字体大小字段时，输入框使用 `14px`。
- 开启后主窗口只显示输入区域和窗口容器。
- 顶部工具栏、底部状态栏、按钮、字符数和调整大小手柄均不可见。
- `Alt+Enter` 可以正常确认粘贴。
- `Escape` 可以正常取消。
- `Alt+Backspace` 可以清空输入。
- 空内容或粘贴失败时短暂显示错误提示，提示消失后保持纯净布局。
- 关闭开关后恢复正常主页面，不需要重启应用。
- 旧设置文件和缺少新字段的设置文件可以正常加载。

## 不在本次范围

- 新建独立窗口或独立页面。
- 修改剪贴板内容格式。
- 增加 mouse hover 工具栏。
- 自动隐藏或延迟显示的工具栏。
- 移动端布局。
- 字体大小影响工具栏、内容库页面、设置页面或 Markdown 预览排版。
- 分别为普通模式和 Markdown 模式设置不同字号。
