# 内容库

## 目标

内容库只保存用户主动添加的重要内容，不再自动记录每次粘贴的文本。用户可以在内容库中新增、编辑、搜索、删除内容，并直接粘贴到打开内容库前的目标应用。

## 入口

- 主输入窗口底部“内容库”按钮。
- 默认全局快捷键 `Alt+R`。
- 托盘菜单“内容库”。

打开内容库时，后端会在尚未记录目标应用时捕获当前前台应用 PID，用于随后直接粘贴。

进入内容库后焦点自动落在搜索框，并选中现有搜索文本。

## 新增和编辑

“新增内容”打开编辑弹窗，字段包括：

- 名称：可选，用于快速识别内容。
- 内容：必填，保存命令、文本或其他需要复用的内容。
- 格式：纯文本或 Markdown。

编辑单条内容时复用同一弹窗。保存后立即写入 `content.json` 并刷新列表。完全相同的文本和格式不能重复保存。

## 列表

内容库提供：

- 按名称和内容搜索。
- 显示名称或首行文本、格式和最后更新时间。
- 单条“预览”“编辑”“删除”操作。
- 点击条目正文直接粘贴。
- 预览内再次提供“编辑”和“粘贴”。
- 按 `↓` 从搜索结果顶部开始选择条目，`↑`/`↓` 继续移动，`Enter` 直接粘贴选中条目。
- 已有选中项时按 `Esc` 先清除选择并回到搜索框，再按一次关闭内容库。

不提供复选框、全选、批量删除或清空全部。删除只针对单条内容，并在删除前确认。

## 直接粘贴

点击“粘贴”时执行：

1. 校验 macOS 辅助功能权限和目标应用 PID。
2. 保存当前剪贴板快照。
3. 按内容格式写入剪贴板。
4. 隐藏内容库窗口。
5. 切回打开内容库前的前台应用并模拟粘贴。
6. 根据 `restore_clipboard` 恢复原剪贴板。

该动作不会打开主输入框，也不需要用户再次确认。粘贴失败时重新显示内容库、恢复目标应用 PID，并通过 `content-paste-error` 显示错误。

## 数据迁移

首次启动新版本时：

- 如果 `content.json` 不存在，会读取旧 `history.json`。
- 只迁移 `kind = "snippet"` 的手动片段。
- 自动生成的 `kind = "history"` 记录不会进入内容库。
- 旧 `history.json` 保留为原始备份，不主动删除。
- 旧片段内容中的 `code` 或其他未知模式按纯文本迁移。

迁移完成后写入 `content.json`，后续只使用新文件。

## 容量

内容库不设置自动淘汰上限，不会因为条目数量增加而静默删除旧内容。删除只能由用户逐条确认执行。
