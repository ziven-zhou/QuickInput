# 设置与快捷键

## 窗口

设置窗口标签为 `settings`，默认尺寸 680 × 620。采用双栏布局，标题栏高度 44px；窗口无边框、透明、置顶，关闭按钮会触发窗口隐藏而不是销毁。

## 设置项

### 快捷键

- 唤起输入框
- 打开内容库
- 打开设置
- 确认粘贴
- 取消

快捷键按钮支持点击后录制组合键。录制结果会统一显示为 macOS 风格符号，但底层保存字符串，例如 `Alt+Space`、`Alt+Enter`。

前三个快捷键注册为系统全局快捷键；确认和取消只在 QuickInput 页面内匹配。

### 窗口

- 窗口弹出位置：屏幕居中或光标附近。
- 记住上次窗口位置：保存主窗口坐标，重启应用后恢复；选择“光标附近”时以光标位置为准。
- 默认窗口大小：UI 提供宽度 400 到 1200、高度 240 到 800；前后端都会把越界值限制到有效范围。
- 窗口背景透明度：UI 范围 10% 到 100%，保存为 `bg_opacity`。
- 默认内容模式：纯文本或 Markdown。
- 纯净输入模式：主窗口只显示输入区域，隐藏工具栏和底部提示。
- 输入框字体大小：范围 12px 到 32px，保存为 `input_font_size`，并带字体预览。

### 剪贴板

- 粘贴后恢复剪贴板。
- 粘贴后窗口保持打开。
- 启用粘贴并发送快捷键：默认关闭。开启后 `Shift+Enter` 在主输入窗口执行粘贴并模拟普通 Enter；原确认快捷键和确认按钮仍仅粘贴，内容库不受影响。

### 启动

- 开机时自动启动，使用 Tauri autostart 插件和 macOS LaunchAgent。

## 自动保存

设置页不提供保存按钮。选择项和开关在修改后立即保存；滑杆和数字输入使用约 220ms 防抖，避免拖动时频繁写盘。关闭设置窗口会立即隐藏窗口，已经排队或正在进行的保存继续在后台完成，不阻塞关闭动作。

前端自动组装完整 `Settings` 并调用 `save_settings`。

后端按以下顺序处理：

1. 校验五个快捷键的格式和冲突；开启粘贴并发送时，把固定的 `Shift+Enter` 一并纳入冲突校验。
2. 归一化窗口尺寸、透明度、位置和内容模式。
3. 注销旧全局快捷键并注册新的三个全局快捷键。
4. 快捷键注册失败时恢复旧快捷键并返回错误。
5. 根据 `autostart` 启用或关闭开机自启。
6. 开机自启操作失败时恢复旧快捷键并返回错误。
7. 写入 `settings.json`。
8. 写入失败时恢复旧快捷键和旧的开机自启状态。
9. 更新内存中的 `Settings`。
10. 发送 `page-shortcuts-updated` 事件。

前端收到事件后刷新主窗口的确认键、取消键、默认内容模式、文字提示、粘贴并发送快捷键开关、背景透明度、纯净模式和输入框字号；内容库也会立即刷新背景透明度，其他页面刷新内容库与设置快捷键。标题栏显示“保存中”“已生效”或“保存失败”等紧凑状态。

## 快捷键冲突

后端会同时检查：

- 唤起
- 内容库
- 设置
- 确认
- 取消

开启粘贴并发送快捷键时还会检查固定的 `Shift+Enter` 与上述五项是否冲突。冲突会阻止保存并提示，不会静默改写自定义快捷键。关闭时不占用该组合键。

空值、无效格式和重复快捷键都会阻止保存。重复判断同时比较规范化字符串和解析后的 `Shortcut`。

## 窗口位置和尺寸

主窗口每次显示时都会应用设置中的逻辑尺寸。

默认尺寸为 `720 × 240`。加载旧设置时，如果宽高仍是旧默认值 `600 × 400`，会迁移为新默认值；用户保存过的其他自定义尺寸保持不变。

位置规则：

- `window_position = "cursor"`：窗口位置设置到当前鼠标位置。
- `remember_window_position = true` 且位置不是光标：恢复 `window_x`、`window_y` 保存的上次位置。
- 保存的坐标不在当前任一显示器的可用区域内时：回退到屏幕居中。
- 其他情况：窗口居中。

主窗口移动时会更新内存坐标；窗口失去焦点、取消、确认、关闭或通过托盘退出时写入 `settings.json`。设置保存时由后端保留最新坐标，避免前端旧表单覆盖。

## 设置页关闭

- 页面内点击关闭按钮或按 `Esc` 时，先取消快捷键录制并立即隐藏窗口；待保存设置继续在后台完成。
- Rust 拦截 `settings` 和 `content` 的关闭请求并改为隐藏。
- 再次打开设置时会居中、显示并聚焦。

## 托盘和单实例

托盘菜单提供打开输入框、内容库、设置和退出。应用使用单实例插件，重复启动时会尝试显示并聚焦已有主窗口。

## 当前实现说明

- 窗口宽高、透明度和弹出位置会在后端再次归一化，避免损坏或手工修改的设置值导致异常窗口。
- 开机自启启用或关闭失败时会返回错误，设置不会显示为保存成功。
- 快捷键录制期间按 `Esc` 只取消录制，不关闭设置窗口；点击录制按钮以外的区域也会取消录制。
- 默认内容模式保存后立即刷新主窗口；取消或确认关闭后的下一次输入会重新使用默认内容模式。
- 修改快捷键默认值时，应同时修改 Rust `Settings` 与 `src/settings.js`，并更新本文。
