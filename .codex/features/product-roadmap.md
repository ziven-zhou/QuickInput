# 产品路线

## 产品定位

QuickInput 是一个跨平台全局快速输入工具：用户在任何应用中按快捷键唤出输入框，确认后内容自动粘贴到原光标位置。

原始产品设计见[产品设计](product-design.md)。本文区分设计目标和当前实现，避免把计划能力视为已完成。

## 核心体验

```text
任意应用输入状态
  → 全局快捷键唤起 QuickInput
  → 输入或编辑内容
  → 选择纯文本或 Markdown
  → 确认
  → 切回原应用并自动粘贴
  → 恢复原剪贴板
```

## 原始 MVP 范围

### Phase 1：核心闭环

- 全局快捷键触发、确认和取消。
- 纯文本模式。
- 剪贴板保存和恢复。
- 切回原应用并模拟粘贴。
- 菜单栏图标和基础设置。
- macOS 与 Windows 目标。

当前代码已覆盖核心闭环，并额外实现了 Markdown、内容库和 Linux 分支。代码模式已按产品决策移除。

### Phase 2：格式增强

计划包括：

- Rich 富文本编辑。
- Markdown 实时预览。
- 图片拖入和粘贴。

当前已完成 Markdown；Code 代码模式已移除，Rich 富文本与图片能力仍属于后续范围。

### Phase 3：体验打磨

计划包括：

- 内容库。
- 快捷键冲突检测。
- 动画过渡。
- 自动更新。

当前已完成内容库和冲突检测；动画和自动更新仍未完成。

## v0.2 内容库目标

[产品设计](product-design.md)中的 v0.2 需求包括：

- `Esc` 取消并隐藏输入框。
- 点击输入框外部取消。
- 统一底部快捷键提示间距。
- 确认后清空输入内容。
- 确认内容持久化到本地。
- 独立内容库页面。
- 单条、批量、全选和清空全部删除。
- 内容库内直接编辑。
- 输入框和托盘提供内容库入口。

当前内容库相关能力已实现。外部点击取消需要按[快速输入](quick-input.md)中的实现差异说明进一步验证。

## 设计中仍待产品确认的事项

产品设计文档保留了以下待确认项：

- 默认快捷键是否使用 `Alt+Space`。
- 是否默认开启开机自启。
- 粘贴完成后是否默认恢复剪贴板。

当前代码对应默认值：

- `trigger_hotkey = Alt+Space`
- `autostart = false`
- `restore_clipboard = true`

如果产品决策变化，应同时更新代码、设置页默认值、本文和[产品设计](product-design.md)。

## 跨平台范围

- macOS：已有明确的问题记录和修复流程，是当前验证最充分的平台。
- Windows：已有焦点和粘贴实现，但 `platform.rs` 当前存在重复 Windows 定义，必须先通过 Windows 目标构建验证。
- Linux：已有 `xdotool` 和 `enigo` 分支，但未列入原始主要发布目标，需要目标桌面环境实测。
